# Skills Simulation Backend Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans proportionally. Complete T0–T5 in order; independent work within one stage may be delegated with explicit file ownership. Record evidence in the adjacent progress ledger.

**Goal:** Implement the specified Sales simulation backend with transparent scoring and private process observations, ready to integrate with the friend's frontend and deploy to a VPS.

**Architecture:** Next.js API routes call modular services with public index.ts boundaries. PostgreSQL holds application data and durable jobs; a separate worker performs generation/evaluation. OpenAI is the confirmed provider; API transport, database repositories and time are injectable for meaningful tests.

**Tech Stack:** TypeScript strict, Next.js, PostgreSQL/pg, Zod, OpenAI, Stripe test mode, SMTP, Vitest, Docker Compose/Caddy.

**Spec:** docs/spec/CONTEXT.md and docs/spec/PROMPT_BACKEND.md. They remain the product authority.

## Global Constraints

- Backend only: contracts, modules, field-packs, prompts, app/api, db, worker, deploy, backend tests and CI. Fixtures in src/mocks/fixtures are the specified exception.
- Do not edit frontend routes/pages, workspaces, ui, screens or frontend handlers/e2e.
- User performs all pushes and PRs; local commits only. Remote: https://github.com/lengway/bc2026.
- No invented production scoring/results. MockProvider is for tests; seeded demo cases do not replace live simulation/evaluation.
- TypeScript strict, no any; validate HTTP/JSONB/LLM boundaries with Zod.
- Hidden data and processObservations never enter public projections. Browser telemetry is untrusted and cannot establish authorship.
- Jury no-login access was explicitly approved via server flag and isolated guest sessions; see the guest-access addendum. No admin UI or frontend changes.

## Review Focus

- Concurrent/retried moves, jobs, submissions and webhook events must not duplicate state, certificates or XP.
- Partial editor logs, IME, paste and missing mouse data must not become skill penalties or authorship claims.
- API/SSE/certificate projection must exclude private persona/rubric/log/editor data.
- LLM output with invented evidence, injected instructions or invalid JSON must not produce unsupported scores.
- Interrupted jobs, expired sessions and replay cursors must recover without exposing another user's data.
