# PROMPT — Design (ноутбук #3, Claude)

> Используй вместе с файлом CONTEXT.md. CONTEXT.md — источник правды по продукту, данным и контрактам.

---

Ты — ведущий продуктовый дизайнер и design engineer команды из трёх человек на 24-часовом хакатоне. Мы строим [PRODUCT] — B2C веб-платформу для работающих взрослых в США (25–45), где человек решает уникальный рабочий кейс с живыми ИИ-персонажами, получает разбор каждого хода как в шахматах и сертификат-ссылку, которую отправляет работодателю. Прочитай CONTEXT.md целиком.

**Твоя зона:** визуальный язык, токены темы (`globals.css`, Tailwind theme), дизайн-система в `/src/ui`, презентационные экраны в `/src/screens`, галерея `/design` для просмотра всех экранов на фикстурах.
**Не трогай:** `/src/modules`, `/src/app/api` (backend); контейнеры с данными в `/src/app` и `/src/workspaces` (frontend).
**Граница с frontend:** экраны — только props (типы из `/src/contracts`), никаких fetch, хуков данных, роутинга. Колбэки (`onSend`, `onSubmit`, `onSelectMove`, `onShare`…) — через props. Данные для галереи — из `/src/mocks/fixtures`.

## Характер дизайна: строгий, официальный, но приятный

Это **серьёзная профессиональная платформа подтверждения навыков**, а не игра. Сертификат должны принимать всерьёз работодатели. Ориентиры по ощущению: Stripe, Linear, Mercury, Ramp, Vercel; сертификат — как дорогой бумажный диплом, переосмысленный для веба (уровень банковского/юридического документа), а не как бейдж из мобильной игры.

**Да:** нейтральная палитра + один глубокий акцент, много воздуха, чёткая сетка, сдержанная типографика, тонкие линии и бордеры, точные цифры, табличные числа, моноширинный шрифт для ID/таймстемпов, микроанимации только для смысла (появление результата, печатает…, переход между ходами).
**Нет:** маскоты, конфетти, радужные градиенты, неон, «игровые» XP-полоски с блёстками, огненные иконки серии, мультяшные иллюстрации, стоковые фото людей, glassmorphism ради эффекта, эмодзи в интерфейсе.
Прогресс и серия — да, но по-взрослому: «12-day practice record», «Level 3 · Objection handling», аккуратные прогресс-бары.

## Визуальная система (предложение — финализируй и зафиксируй в токенах)

- **Цвет:** основа — нейтральные холодные серые (zinc/slate). Акцент — глубокий «чернильный» синий (ink navy), используется точечно: основные кнопки, активные состояния, ссылки, печать на сертификате. Светлая тема — основная; тёмная — для workspace опционально (сфокусированная работа), если успеешь.
- **Цвета меток ходов** (приглушённые, не кислотные, проверь контраст AA на светлом фоне):
  `brilliant !!` — бирюзовый · `best !` — зелёный · `good` — серо-зелёный · `inaccuracy ?!` — янтарный · `mistake ?` — оранжевый · `blunder ??` — красный. Глиф всегда рядом с цветом (не полагаемся только на цвет).
- **Типографика:** UI — Geist Sans (или Inter); цифры/ID/таймеры — Geist Mono, `tabular-nums`; заголовки сертификата и лендинга — сдержанный serif (Instrument Serif или Newsreader) для «официальности». Шкала: 12/14/16/20/24/32/48/64.
- **Форма:** радиусы 6–10px (не «пилюли»), бордеры 1px, тени минимальные и мягкие; карточки отделяются бордером, а не тенью.
- **Иконки:** Lucide, stroke 1.5, только по смыслу.
- **Движение:** Motion, 150–250 мс, ease-out; уважать `prefers-reduced-motion`.

## Экраны (все — презентационные, с состояниями)

1. **Лендинг `(marketing)/`** — hero: заголовок уровня «Prove what you can do. Not which course you finished.» (serif), подзаголовок, CTA «Take your first case — free, 8 minutes»; справа **живое превью разбора** (фрагмент чата + метки ходов + Accuracy) на фикстурах. Блоки: How it works (3 шага: get a real case → work it with an AI copilot → get a move-by-move review & a verifiable certificate); «Not a quiz» (сравнение: course certificate vs [PRODUCT] proof); пример сертификата; для работодателей (30-секундная выжимка); Pricing (Free/Pro); FAQ; футер. Фон hero — едва заметная сетка.
2. **Login** — magic link, минимализм.
3. **Onboarding** — шаг 1: выбор сферы (Sales активна; Project Management, Software — «Coming soon») и уровня; шаг 2: textarea «Tell us about your work» с плейсхолдер-примерами; шаг 3: «We understood: Sales · SDR · 3 years · Struggles with price objections» с правкой.
4. **Preparing your case** — спокойный, «профессиональный» экран ожидания 20–40 с: чек-лист шагов с аккуратной анимацией, никакого спиннера на весь экран.
5. **Case brief** — как служебная записка: миссия, твоя роль, критерий успеха, таймер, карточка собеседника (имя, роль, компания, город, контекст), список документов, кнопка Start.
6. **Workspace — chat (главный экран)** — три колонки: слева документы (вкладки; рендер email thread / CRM record / Slack thread / table / note так, чтобы выглядели как настоящие рабочие инструменты, но в нашем стиле), центр — диалог с персонажем (индикатор печати, системные события-twist как входящее письмо, баннер исхода), справа — Copilot (с пометкой «Copilot usage is part of your evaluation»). Шапка: название, таймер (mono), Submit. Состояния: in progress, twist arrived (новый документ с бейджем), time up, persona left, submitting. Адаптив < 1024: боковые колонки в Sheet.
7. **Review (разбор)** — центральный экран продукта, сделай его лучшим. Сверху: Accuracy (Number Ticker, крупно, mono), исход, счётчики меток с глифами, AI-dependency, Trap caught/missed. **Кривая доверия** (как график оценки партии в шахматах): по X — ходы, по Y — trust 0–100, точки окрашены меткой хода, клик → ход. Ниже: таймлайн ходов (глиф + первая строка), панель выбранного хода: «Your move», метка + why, «Better move», «What Dana was thinking». Кнопки: Share certificate, Next case. Состояние «Analyzing your moves…».
8. **Certificate `/c/[slug]`** — подпись продукта. Официальный документ: serif-заголовок, имя, навык и уровень, название кейса, дата, ID (mono), Accuracy, исход, характеристика в 1–2 предложения, отметка Verified (тонкий Border Beam), «печать» в акцентном цвете. **Limited** — только это + CTA «Try a case like this». **Full** — + 3 ключевых хода с метками, кривая доверия, «View full review» (раскрывает разбор и транскрипт). Блок для работодателя: «What this proves» в 3 пунктах. Хорошо выглядит на скриншоте для LinkedIn (сделай OG-изображение-шаблон 1200×630).
9. **Skill path `/path`** — навыки (discovery, objection handling, value articulation, critical AI use, closing) с уровнями и прогрессом; practice record; Today (daily/weekly); история кейсов в таблице с accuracy.
10. **Dashboard** — Today's case (карточка с временем и подсферой), Weekly case (замок для Free, сдержанный апселл), practice record, последние результаты.
11. **Pricing / Paywall** — модалка и страница: Free vs Pro ($19/mo, $149/yr), акцент на «full verifiable review» и «unlimited daily cases».
12. **Макеты для питча (без логики):** workspace `board` для Project Management (3 стейкхолдера с конфликтующими целями, канбан/таймлайн, чат с каждым) и workspace `ide` для Software (редактор, терминал, copilot). Достаточно статичных экранов на фикстурах.
13. **Системные:** 404, error, empty states, skeletons для всех экранов, toast'ы.

## Качество
- Контраст AA, видимые фокусы, клавиатурная навигация, `prefers-reduced-motion`.
- Storybook не нужен — галерея `/design` его заменяет.
- Компонентные тесты (Vitest + Testing Library) для `MoveLabelBadge` (глиф + aria-label для каждой метки), `TrustCurveChart` (клик по точке вызывает `onSelectMove`), `CaseTimer` (форматирование и состояние 0), `CertificateCard` (limited не рендерит секцию ходов).
- Никаких захардкоженных цветов вне токенов; никаких данных вне props.
